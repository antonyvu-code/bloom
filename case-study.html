Why the portfolio is a garden.

BLOOM turns a real habit — one morning of design research, every day — into something that grows on screen instead of sitting in a grid. This is the reasoning behind it: what it solves, why it looks the way it does, and how it keeps itself honest.

▶ Open the live garden

01

The premise

Most portfolios show finished things — a gallery of thumbnails a hiring lead skims in eight seconds. That format hides the part that actually predicts good work: the habit underneath it. BLOOM makes the habit the subject. The page is not a list of projects; it is a picture of the discipline that feeds every project.

The argument is literal. Each flower is one morning of research, so a fuller garden simply means more mornings — the visual and the claim are the same thing.

02

A garden, not a grid

The metaphor sets every other decision. A garden is warm, slow, and cumulative — it rewards returning, not scanning. So the palette is a warm field of terracotta, amber, rose, gold and rust on a paper cream #f5efe4, the type is a single serif, and the one motion is growth: stem, then leaf, then head. There is no dashboard chrome, because a garden has none.

One accent does the pointing — terracotta #c9552f — used only for the eyebrow, the count, and links. Everything else stays ink on paper.

03

Generative, but never random-looking

No two mornings are alike, so no two flowers are hand-placed. Each bloom's petal count, head size, stem height, sway and colour come from a tiny hash — sin(seed × 12.9898) × 43758.5, the fract of it taken as a unit value. The trick is where the randomness is allowed: hue is picked from a fixed warm set, and saturation and lightness only wander inside a narrow band. The result reads as a coherent garden that still never repeats a flower.

Constrained generativity is the whole craft here — total randomness looks like noise, and a fixed template looks stamped. The value sits in the deliberately small window between them.

04

Why Canvas 2D and GSAP, not WebGL

A garden of a few dozen flowers is O(n) with a small n. Canvas 2D draws it at 60fps on any laptop, ships in a fraction of the bytes, and is trivial to debug. Reaching for WebGL here would be over-engineering — and knowing when not to reach for the GPU is itself the senior signal. Growth is a single number from 0 to 1 tweened by GSAP with elastic.out(1, 0.65); the draw loop reads that number, nothing more.

The render loop pauses itself. An IntersectionObserver stops it when the garden scrolls out of view, visibilitychange stops it when the tab is hidden, and under prefers-reduced-motion it settles the moment every flower has finished growing — no frames are spent on pixels no one is watching.

05

The count is real

The page claims each flower is one morning of research, so that number is not typed by hand. A prebuild step (scripts/count-mornings.mjs) scans the actual daily-research log — the sibling webdesign-digest folder — counts every YYYY-MM-DD.md entry, and writes the total into a generated module the app imports. Add tomorrow's entry and the seeded garden grows by one flower on the next build, untouched by me.

It fails safe: if the log is missing at build time the count falls back to a single flower dated today — the page would rather understate the habit than invent one.

06

Accessibility on a generative canvas

A drawn garden is invisible to a screen reader, so the meaning lives in the DOM, not the pixels. The count sits in an aria-live region and updates as you plant; the canvas is aria-hidden because it carries no information the text doesn't. There is a skip link, landmark structure, visible focus rings, and the terracotta accent is checked to hold WCAG AA contrast on the cream ground. Motion is a preference the page obeys, not a default it imposes.

07

What I'd grow next

The pipeline is built to widen. The same prebuild that counts mornings could read each entry's topic and seed that day's flower from it, so the garden's colours would carry meaning rather than only warmth. A nightly job could rebuild the page each morning, so the portfolio is never more than a day stale — a garden that literally keeps growing while I sleep.

The page is a demo of the ritual. The real thing happens every morning.
